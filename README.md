# OJ-QWEN 1.2.3

Неофициальное браузерное расширение (Manifest V3), превращающее бесплатный [chat.qwen.ai](https://chat.qwen.ai) в полноценный вайбкод-клиент прямо в виде оверлея поверх вкладки — без API-ключей, локальных серверов, Node.js и ручной правки системного промпта.

Работает в **Google Chrome**, **Яндекс Браузере**, **Microsoft Edge**, **Brave**, **Opera** и других браузерах на базе Chromium.

---

## Возможности
- **Чистый оверлей поверх `chat.qwen.ai`** — открывается кнопкой `OJ-QWEN` внизу справа или клавишей `Alt + Q`.
- **Прямой API-слой + проекты:** мгновенно загружает все проекты Qwen и все чаты проекта (включая многостраничные списки); по умолчанию используется проект `OJ-QWEN` (создаётся автоматически).
- **Счётчик контекстного окна (1M токенов):** оценка загрузки оригинального чата, полоса заполнения и процент `0,0%`.
- **3 режима безопасности (в Настройках):**
  - *Всё спрашивать* (по умолчанию);
  - *Разрешать всё, кроме удаления* (файлов и папок);
  - *Всё разрешать* (без подтверждений).
  Все правки, удаления и переносы сохраняют локальный бэкап с откатом в 1 клик.
- **12 файловых инструментов:**
  - `list(dir?, depth?, pattern?, offset?)` — дерево файлов с глубиной и пометкой бинарных файлов;
  - `search(query, regex?, dir?, caseSensitive?, maxResults?)` — поиск по проекту;
  - `read(path, startLine?, endLine?, offset?)` — чтение файлов до 256 КБ;
  - `validate(path)` — локальная CSP-безопасная проверка синтаксиса и баланса скобок (JSON, XML/SVG, JS/TS, CSS/SCSS/LESS, Python, Java, Go, Kotlin, Swift);
  - `mkdir(path)` — создание папок (включая вложенные);
  - `create(path, text)` — создание новых файлов;
  - `edit(path, version, find/replace | edits:[...])` — одиночная и атомарная мульти-правка (с поддержкой CRLF);
  - `write(path, version, text)` — полная перезапись существующего файла с проверкой версии;
  - `diff(path)` — отличия от предыдущего снимка;
  - `rename(from, to)` — переименование и перемещение файлов и папок;
  - `delete(path)` — удаление файла с бэкапом;
  - `rmdir(path, recursive?)` — удаление пустых и непустых папок с бэкапом текстовых файлов (защищает `.git`, `.env`, `node_modules`).
- **8 агентных инструментов + вкладка «Планы» с историей:**
  - `plan_create`, `plan_update` (атомарный), `plan_accept` (строгая самоприёмка с `evidence`), `plan_abort`;
  - `memory_save`, `memory_read`, `memory_delete`;
  - `ask_user(question, options?)` — уточняющие вопросы с вариантами ответа прямо во время работы.
- **Автопроверка обновлений и баг-репорты:** при открытии оверлея тихо проверяется свежий релиз (раз в 6 часов) с ненавязчивым индикатором под логотипом, скрипт `Обновить.cmd` в архиве обновляет файлы на месте, а кнопка «Сообщить об ошибке» внизу справа формирует безопасный отчёт без переписки.

## Установка (без Git и Node.js)
1. Скачай свежий архив **`OJ-QWEN-*.zip`** со страницы [Releases](https://github.com/offlinejust/OJ-QWEN/releases/latest).
2. Распакуй его в постоянную папку (например, `C:\OJ-QWEN`).
3. Открой страницу расширений (`chrome://extensions`, `browser://extensions` или `edge://extensions`).
4. Включи **Режим разработчика** → **Загрузить распакованное расширение** → укажи папку `extension` внутри распакованного архива.
5. Открой [https://chat.qwen.ai](https://chat.qwen.ai), войди в аккаунт и нажми **OJ-QWEN** внизу справа (или `Alt + Q`).
6. Нажми **«📁 Выбрать папку»** в шапке чата и укажи подпапку проекта.

> Ограничение Chromium: `showDirectoryPicker` не позволяет выбрать корень диска `C:\`, сами `Документы` или `Рабочий стол` — выбирайте конкретную подпапку проекта внутри них.

## Как обновлять
1. Запусти двойным кликом **`Обновить.cmd`** в той же папке — скрипт сам проверит последний релиз на GitHub и обновит файлы в `extension/` на месте.
2. Открой страницу расширений в браузере и нажми кнопку обновления (**↻**) у OJ-QWEN.

Все настройки, планы, заметки и бэкапы сохраняются.
