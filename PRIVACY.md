# Политика конфиденциальности OJ-QWEN

**OJ-QWEN** — неофициальное браузерное расширение с открытым исходным кодом, добавляющее локальный интерфейс для работы с файлами поверх `https://chat.qwen.ai`.

## Какие данные обрабатываются
1. **Локальное хранилище браузера (`chrome.storage.local` и `chrome.storage.session`):**
   - Настройки расширения (выбранный проект, режим безопасности, отправка по Enter).
   - История шагов, планы, заметки памяти агента и резервные копии изменённых файлов для отката.
   - Состояние открытия оверлея для текущей вкладки.
   - Все эти данные хранятся **только локально на устройстве пользователя** и никогда не отправляются разработчику расширения.

2. **Доступ к локальной папке проекта (File System Access API):**
   - Доступ к файлам открывается **только** к той подпапке, которую пользователь явно выбрал через системное окно браузера.
   - Расширение блокирует чтение и изменение скрытых/чувствительных файлов (`.env`, `.git`, приватные ключи, `node_modules`).
   - Фрагменты файлов, которые модель запрашивает в рамках диалога, передаются исключительно в текущий чат `https://chat.qwen.ai` (в рамках политики конфиденциальности Qwen).

3. **Проверка обновлений (по нажатию кнопки):**
   - Только когда пользователь сам нажимает **«Проверить обновления»** в Настройках, расширение делает анонимный GET-запрос к публичному GitHub Releases API (`https://api.github.com/repos/offlinejust/OJ-QWEN/releases/latest`), чтобы сравнить номер текущей и последней версии. Никакие пользовательские данные при этом не передаются.

## Что расширение НЕ делает
- Не имеет собственных серверов, аналитики, трекеров и телеметрии.
- Не собирает и не передаёт пароли, токены, историю браузера или содержимое чатов третьим лицам.
- Не загружает и не исполняет удалённый код.
